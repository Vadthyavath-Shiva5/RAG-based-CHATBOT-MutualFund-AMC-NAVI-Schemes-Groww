# Mutual Fund FAQ Assistant – RAG Chatbot (NAVI AMC)

This project is a **RAG-based FAQ chatbot** built as part of the **Neatleap Learn in Public (LIP) Challenge – Milestone 1**.

The chatbot answers **facts-only questions about mutual fund schemes** using **official public sources only** such as AMC pages, SEBI regulations, and AMFI investor education materials.

⚠️ The assistant does **not provide investment advice**.  
All responses include **source citations**.

---

## Problem Statement

Build a **facts-only mutual fund FAQ assistant** that answers questions such as:

- Expense ratio
- Exit load
- Minimum SIP
- ELSS lock-in period
- Riskometer / Benchmark
- Mutual fund documentation guidance

Constraints:
- Public sources only (AMC / SEBI / AMFI)
- Every answer must include **a citation link**
- Refuse opinion-based queries like **“Should I invest?”**
- Responses must be **≤ 3 sentences**
